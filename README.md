# Mesut IPTV

مشغّل IPTV بواجهة عربية/فرنسية/إنجليزية. التطبيق **مشغّل فقط**: لا يحتوي على أي قنوات أو اشتراكات، ويستخدم مصادرك المصرّح لك بها.

## الحالة (المرحلة 1)
- هيكل Capacitor كامل، Package ID: `com.mesut.iptv`، الحد الأدنى Android 10 (API 29)، دعم Android TV.
- واجهة RTL، تبويبات، إعدادات (اللغة، المظهر، مسح الذاكرة المؤقتة، معلومات التطبيق).
- إدارة المصادر: Xtream Codes وM3U (رابط أو ملف من الهاتف) وXMLTV، مع الحفظ والتعديل والحذف والتحديث.
- أيقونة وSplash Screen، وGitHub Actions يبني APK وAAB.
- **غير منفّذ بعد:** مشغل الفيديو، قائمة القنوات، الأفلام والمسلسلات، EPG المرتبط بالقنوات (المرحلتان 2 و3).

## البناء من هاتفك (بدون كمبيوتر)
1. أنشئ مستودعاً جديداً على github.com من متصفح الهاتف.
2. ارفع محتوى هذا المجلد (Add file > Upload files)، مع مجلد `.github/workflows`.
3. افتح تبويب **Actions** ثم **Build Mesut IPTV** ثم **Run workflow**.
4. بعد انتهاء البناء (حوالي 10 دقائق) نزّل `Mesut-IPTV` من قسم Artifacts: يحتوي على `Mesut-IPTV.apk` (للتثبيت المباشر) و`Mesut-IPTV.aab`.

## ملاحظات
- ملف AAB غير موقّع؛ للنشر على Google Play يلزم توقيعه بمفتاحك الخاص.
- APK الحالي موقّع بمفتاح debug وهو صالح للتثبيت والتجربة.
- كلمات مرور Xtream تُحفظ حالياً في تخزين التطبيق الخاص، وسيُنقل في المرحلة 2 إلى تخزين مشفّر.
